# Editor and Run Configuration

## Prerequisites
- Visual Studio Code or Antigravity IDE
- C/C++ Extension (`ms-vscode.cpptools`) for C++ debugging
- Node.js (for `node-terminal` launch configuration support)
- CMake Tools (optional, for preset auto-detection)

## Configurations
- `Run Packaged Workbench`: Launches the packaged root `Launch.exe` binary.
- `Launch Backend (Debug)`: Launches the unmanaged backend server binary directly under the MSVC debugger with test parameters.
