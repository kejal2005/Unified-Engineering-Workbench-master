# PROMPT 20: Documentation, report and final submission (Stage 12)

## Requirements
1. `README.md`: prerequisites, one-click steps, architecture, supported formats, build/test steps, limitations, SmartScreen note, editor run configuration.
2. `docs/REPORT.md` (<= 6 pages when exported to PDF, excluding handwritten appendix): design choices, FEA verification, performance results, embedded design, test outcomes, limitations, actual effort hours. Every number traceable to a `results/` file.
3. `docs/AI_USE_LOG.md`: real tools/models, representative prompts, outputs, manual edits, validation evidence, and genuine challenge test outcomes.
4. `docs/OWNERSHIP.md`: original vs reused work.
5. Final labelled plots in `results/plots/`, raw CSVs in `results/csv/`, benchmark files in `results/benchmarks/`.
6. Git: create bundle (`git bundle create`) and readable `commit_log.txt`; verify `git clone` from bundle builds.
7. Demo evidence: 3-5 min video script or timestamped screenshot walkthrough with logs (`docs/evidence/`).
8. Run final checklist (Part 8) and fill in results truthfully.

## Acceptance
The ZIP extracts, launches, and every checklist item is either evidenced or listed as a known limitation.

## Stop If
Any claim in report lacks a source file.
