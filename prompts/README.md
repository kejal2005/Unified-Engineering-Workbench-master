# Sequential Implementation Prompts Pack

This directory contains the 20 sequential implementation prompts from the Implementation Blueprint (`tet.md`).

## Usage Protocol
Each prompt is designed to be executed sequentially with the standard Preamble and Footer blocks found in `00_preamble_and_footer.md`.

Format for each run:
```
[PREAMBLE]
+ Prompt Body
+ [FOOTER]
```
